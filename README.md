# GBD 2021 neonatal infection mortality analysis

Analysis code for **Global mortality and sociodemographic inequalities in neonatal sepsis and other neonatal infections, 1990-2021, with projections to 2030: an ecological analysis of GBD 2021**.

## Scope and data availability

This is a code-only reproducibility package. It does not distribute IHME exports, UNICEF responses, reconstructed individual simulations, manuscript files, correspondence or participant-level data. Numerical datasets are intentionally absent pending verification of redistribution permissions; this is not evidence that the source inputs are private participant data. Obtain the inputs from the documented providers under their applicable terms. The exact retained-input schemas, counts and SHA-256 fingerprints are in `metadata/input_manifest.json`. This package must not be described as containing openly deposited processed data.

The primary indicator is neonatal deaths at ages 0-27 days, both sexes, divided by corresponding live births and multiplied by 1,000. Historical analyses use 1990-2021. The forecast covers 2022-2030. Global numerator and denominator series are separate published Global estimates and are not forced to equal country sums. National SDI groups are fixed by 2021 classification and do not reproduce native GBD SDI aggregates.

## Requirements

The analysis environment used R 4.5.1 with forecast 8.24.0, data.table 1.17.8, matrixStats 1.5.0, dplyr 1.1.4, tidyr 1.3.1, readr 2.1.6, readxl 1.4.5, countrycode 1.6.1, jsonlite 2.0.0, ggplot2 4.0.1, sf 1.0-23, rnaturalearth 1.1.0 and ragg 1.5.0. Also install patchwork and stringr, used by the figure scripts. Python 3 is required; install the packages in `requirements.txt`. This records versions used, not an automatically resolved environment lockfile. Matching versions and platform can matter for exact numerical/graphics reproduction.

Arial is required to reproduce the original typography. `sf` and `ragg` may require system libraries. The map script obtains Natural Earth medium-scale boundaries through rnaturalearth when its local cache is absent; internet access may be required. Figures are saved as separate 600-dpi LZW TIFF panels. Palettes and the scientific computation were preserved from the production scripts; path handling was adapted for portability.

## Reproduction

1. Obtain the nine files in `DATA_SOURCES.md`, rename them to the manifest filenames, and place them in `inputs/`. Source exports may include years outside the analytical window; filtering is performed by the scripts. Do not substitute a GBD 2023 download for GBD 2021.
2. Install the R dependencies listed above and run `python3 -m pip install -r requirements.txt` in the environment you intend to use.
3. From this repository, run `python3 scripts/prepare_inputs.py --check-only` to check file availability. Different fingerprints generate warnings because a fresh provider export may differ from the retained extract.
4. Run `python3 run_all.py`. This stages local inputs, generates point analyses, runs forecasting and country/group uncertainty simulations, performs external magnitude checks, redraws final intervals, and exports one formal CSV/XLSX per Table S1-S5 with separate plain-text notes. The formal table values follow the production definitions; Excel styling is not a replica of the manually formatted submission Word files.
5. Review the validation reports and generated outputs. A successful run verifies internal consistency, not external scientific validity or guaranteed interval coverage. Re-running overwrites local generated outputs, not `inputs/` or any original manuscript files. Expect a computationally intensive run and substantial local disk use from simulations and TIFFs.

## File map

- `assets/Figure1-Figure6/`: production R entrypoints for the six main figures.
- `assets/Figure_S1_SDI_absolute_gap/` and `assets/Figure_S2_Concentration_curve_difference/`: standalone supplementary plot scripts; their CSVs are generated by the full analysis.
- `scripts/complete_uncertainty_analysis.R`: country, continent and SDI-group simulations, inequality changes, ranks and frontier uncertainty.
- `assets/Figure3/Figure3.R`: global forecast, nested rolling-origin validation, fitting-window and input-dependence sensitivity.
- `scripts/build_external_comparison_tables.py`: UN IGME magnitude checks and compatible published-value concordance.
- `scripts/prepare_final_excel_tables.py` and `scripts/export_formal_tables.py`: final table definitions and exports.
- `metadata/input_manifest.json`: expected input schemas, record counts and source fingerprints; no source data rows.

Each main-figure entrypoint contains its corresponding analysis; unused historical figure branches have been removed. Figure3 uses the rebuilt time-series analysis, not an APC model. Point-only graphics written during staging are subsequently replaced by the interval rendering stage; publication outputs are the final files after the full run.

## Interpretation limits

Derived intervals are conditional approximate simulation intervals reconstructed from published marginal summaries, not original IHME joint-draw uncertainty intervals. Dependence assumptions are specified rather than empirically recovered. Country simulations use 4,000 central and 1,200 per alternative scenario; global forecasting uses 2,000 central and 600 per alternative. Seeds and assumptions are retained in the source. The empirical frontier and rank ranges are descriptive. Global forecasts are exploratory pointwise distributions, not validated joint trajectories. UN IGME is an all-cause magnitude check, not independent validation of this GBD cause. A matched official forecast comparison and cause-specific VR/VA country-year coverage quantification were not completed.
